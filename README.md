## Overview

BMI Calculator is a Python-based application developed as part of the Oasis Infobyte Python Programming Internship. This application calculates the Body Mass Index (BMI) using the user's weight and height and categorizes the result according to standard health classifications.

---

## Features

- User-friendly command-line interface
- Calculates Body Mass Index (BMI)
- Displays BMI with two decimal precision
- Categorizes BMI into:
  - Underweight
  - Normal Weight
  - Overweight
  - Obese
- Handles invalid and non-numeric inputs
- Lightweight and easy to use

## BMI Formula

```text
BMI = Weight (kg) / Height² (m²)
```
