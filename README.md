# BMI Calculator

A simple and user-friendly BMI Calculator built using Python.

## Features

- Accepts weight in kilograms
- Accepts height in meters
- Calculates BMI
- Displays the BMI value
- Shows the BMI category

## Technologies Used

- Python 3
- VS Code
- Git & GitHub

## How to Run

1. Clone or download the project.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python bmi.py
